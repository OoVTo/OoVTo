```

║        🗺️  Lost & Found — Mapped in Real Time  🔍        ║
```

A Laravel-powered interactive mapping platform that reunites people with their lost belongings. Users drop pins on an OpenStreetMap interface to report lost items; finders respond through a built-in notification system.
